> Нужно получить предыдущую продажу для каждого клиента отдельно.

| date  | customer_id | amount |
| ----- | ----------: | -----: |
| 01.08 |           1 |    100 |
| 02.08 |           1 |    150 |
| 03.08 |           1 |    120 |
| 01.08 |           2 |    500 |
| 02.08 |           2 |    450 |
| 03.08 |           2 |    600 |



with tt as (
    select
    *,
    lag(amount) over(PARTITION BY customer_id ORDER BY date) as r
    from sales
)

select *
from tt;





Нужно найти последнюю продажу каждого клиента.


with tt as (
    select
    *,
    row_number() over(PARTITION BY customer_id ORDER BY date DESC) as r
    from sales
)

select 
*
from tt
where r = 1;



Задача

Нужно получить самую последнюю транзакцию каждого клиента.

Но есть условие:

Если у клиента несколько транзакций в одну и ту же дату, нам нужна только одна, с самым большим transaction_id.


| transaction_id | customer_id | date  | amount |
| -------------: | ----------: | ----- | -----: |
|            101 |           1 | 03.08 |    120 |
|            102 |           1 | 03.08 |    200 |
|            103 |           1 | 02.08 |    150 |
|            104 |           1 | 01.08 |    100 |
|            201 |           2 | 03.08 |    500 |
|            202 |           2 | 02.08 |    450 |
|            203 |           2 | 01.08 |    400 |



with tt as (
    select
    *,
    row_number() over(PARTITION BY customer_id ORDER BY date DESC, transaction_id DESC) as r
    from sales
)

select
*
from tt 
where r=1;
