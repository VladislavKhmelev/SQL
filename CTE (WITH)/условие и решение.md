Первая задача на CTE

Теперь сделаем чуть интереснее.

Нам нужно получить среднюю зарплату по каждому городу.


with tt as (
    select 
    city
    avg(salary)
    from employees
    GROUP BY city
)

select 
*
from tt;




Задание

Нужно вывести только те города, где средняя зарплата больше 100 000.


with tt as (   
    select  
    city,
    avg(salary) as t1
    from employees
    group by city
)

select 
*
from tt
where t1 > 100000;
